## KIRA für Mac 0.2.0

**Neu**

- **Anmeldung über Microsoft im Browser.** Im App-Fenster hing die
  Microsoft-Anmeldung bei „Face, fingerprint, PIN or security key“, weil eine
  App wie diese keine Passkeys erreicht. „Mit Microsoft anmelden“ öffnet jetzt
  deinen Browser. Dort klappen Passkeys, Touch ID und das Handy als Schlüssel.
  Danach springt die Anmeldung zurück in die App. Safari fragt beim ersten Mal,
  ob KIRA geöffnet werden darf: „Erlauben“. Braucht KIRA 3.299.0 auf dem
  Server.
- **Diktat auf der 🌐 fn-Taste.** Einstellungen → Tastenkürzel → Diktat →
  „fn-Taste“. Kurz tippen schaltet das Diktat an und aus, gedrückt halten heißt
  sprechen, loslassen setzt den Text ein. fn zusammen mit einer anderen Taste
  bleibt, was es war. Tipp: In den Tastatur-Einstellungen von macOS für die
  fn-Taste „Keine Aktion“ wählen, sonst öffnet sich zusätzlich die
  Emoji-Auswahl. Die Einstellungen der App zeigen das samt Knopf an.
- **Neues App-Symbol** mit dem KIRA-„K“ in der Glas-Sprechblase.
- In der Einrichtung steht neben den Kürzeln „Ändern“.

**Behoben**

- Ein Diktat, das noch startete, ließ das Mikrofon nach dem Stoppen weiterlaufen.
- Ohne Anmeldung fragt die App den Server nicht mehr im Sekundentakt nach
  Mitteilungen.

Die App aktualisiert sich selbst und installiert das Update beim nächsten
Beenden (oder sofort über die Menüleiste → „Nach Updates suchen“).
