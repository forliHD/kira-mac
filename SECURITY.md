# Sicherheit

## Unterstützte Versionen

Sicherheitsupdates gibt es nur für die **letzte veröffentlichte Version**
(das aktuelle Release von
[forliHD/kira-mac](https://github.com/forliHD/kira-mac/releases)).

## Schwachstellen melden

Bitte melde Sicherheitslücken **privat**, nicht in einem öffentlichen Issue
oder Pull Request.

- Bevorzugt über
  [GitHub Security Advisories](https://github.com/forliHD/kira-mac/security/advisories/new)
  (nur für den Eigentümer sichtbar).
- Alternativ den Eigentümer direkt über
  [GitHub @forliHD](https://github.com/forliHD).

Bitte nenne die betroffene Version, was das Problem ist und – soweit möglich –
wie es sich nachstellen lässt. Eine Bestätigung folgt, sobald die Meldung
angekommen ist. Details werden veröffentlicht, wenn eine Korrektur bereitsteht.
